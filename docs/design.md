# 界面设计

## 设计语言

参考 WorkBuddy 资料库风格：明快、圆润、玻璃拟态，适合小学生审美。

| 元素 | 规范 |
|---|---|
| 主题色 | 粉 `--sp-pink`、紫 `--sp-violet`、青绿 `--sp-teal`（渐变组合为主视觉） |
| 卡片 | 白色半透明 + 大圆角（16~24px）+ `backdrop-filter: blur` + 柔和投影 `0 16px 42px rgba(57,47,103,.2)` |
| 字体 | 系统字体栈，标题加粗大字号，正文≥14px |
| 动效 | 按钮/卡片 hover 轻微上浮，激活态渐变填充 |
| Logo | `client/public/logo.png`，favicon 同源 |

## 主流程（家长先行）

```text
未登录
  → 主视觉区「进入家长登录」按钮（唯一入口）
  → 家长登录（PIN 输入 或 跳转 Casdoor）
  → 家长中心：查看/创建/删除学生、发布任务、新增奖励、确认兑换、修改 PIN
  → 选择/创建学生
  → 学生学习工作台（学习地图）
  → 进入模块闯关 → 结算（星级/连击/积分）→ 返回地图
```

规则：

- 未登录不暴露任何学习内容。
- 登录后家长中心入口保留在顶部；退出登录清除 `localStorage.sp_parent_jwt`。
- 底部菜单在登录后显示，切换工作台各视图。

## 页面结构

### 1. 登录引导页（未登录）

- 品牌主视觉 + Logo + 一句产品介绍。
- 单个「进入家长登录」主按钮（**全页仅此一个登录入口**，历史版本曾出现顶部+主视觉双按钮重复，已修复）。

### 2. 家长登录弹层/页

- PIN 模式：四位数字输入 + 登录按钮。
- Casdoor 模式：「使用 Casdoor 登录」跳转按钮。
- 失败反馈：**居中阻塞式 modal**（不用底部 toast）。

### 3. 家长中心

- 学生卡片列表：头像、姓名、年级；支持新建（姓名/用户名/头像 emoji/年级）、删除（至少保留一个）。
- 任务管理：发布任务（标题/类型/截止日/积分/目标学生）、删除。
- 奖励管理：新增奖励（名称/所需积分）、查看兑换申请并确认。
- 修改 PIN、退出登录。

### 4. 学生学习工作台（学习地图）

- 顶部：当前学生头像/昵称、积分（累计+今日）、连击火焰、切换学生入口。
- 学习地图：六大模块入口卡片——
  - 📖 单词卡片（翻转记忆 + 掌握加分）
  - 🐢 语文阅读（短文 + 理解题）
  - 🔢 数学题目（即答即讲）
  - ✅ 每日任务（逾期标红）
  - 🎁 奖励兑换（提交 → 家长确认）
  - 📈 成长统计（积分流水、练习记录、星级）
- 闯关界面：题目卡片 + 选项，实时反馈对错、连击数、本题得分。
- 结算页：星级展示（0~3 星）、正确率、连击最高、获得积分。

### 5. 底部菜单（双端兼容）

```css
.bottom-menu{
  position:fixed; left:50%; bottom:18px; transform:translateX(-50%);
  z-index:20; width:min(620px, calc(100% - 32px)); height:72px;
  display:grid; grid-template-columns:repeat(4,1fr); align-items:center;
  border-radius:24px; background:rgba(255,255,255,.92);
  box-shadow:0 16px 42px rgba(57,47,103,.2); backdrop-filter:blur(18px);
}
.bottom-menu button.active{
  color:#fff; background:linear-gradient(135deg,var(--sp-pink),var(--sp-violet));
}
```

4 个入口（当前）：工作台 / 学习 / 任务 / 我的（积分成长）。

## 响应式规则

| 断点 | 适配 |
|---|---|
| >768px（PC） | 内容区居中 max-width，卡片网格多列 |
| ≤768px（手机） | 学习单元单列；底部菜单固定，适配安全区域 `env(safe-area-inset-bottom)`；字号略降 |
| 触控 | 按钮最小点击区 44px；无 hover 依赖 |

## 状态与反馈

| 场景 | 呈现 |
|---|---|
| 接口报错 | 居中阻塞式 modal（错误文案 + 确认按钮） |
| 登录态失效（401） | 自动清除会话 → 回登录引导页 |
| 加载 | 按钮内联 loading / 骨架占位 |
| 成功 | 卡片轻反馈（星级跳动、积分 +N 飘字） |
