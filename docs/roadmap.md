# 开发计划

## 已完成 ✅

### v0.1.x 基础平台

- [x] Logo 品牌接入（favicon + 页面 + README）
- [x] 客户端/服务端分目录（`client/` + `server/`）
- [x] 客户端迁移 Vue 3 + Vite
- [x] 服务端 GoFrame 脚手架分层重构（cmd/controller/service/model/middleware）
- [x] 移除 Nginx：GoFrame 直接托管 Vue 静态资源，单容器架构
- [x] 部署 217 测试服务器（`http://192.168.50.217:18180/`）

### 功能

- [x] 六大学习模块：单词卡片、语文阅读、数学题目、每日任务、积分、奖励兑换
- [x] 多学生账号：家长创建/切换，数据按 `child_id` 隔离
- [x] 家长认证：Casdoor SSO（OIDC）+ PIN bcrypt 回退，自动识别模式
- [x] 多邻国式闯关：练习场次、连击阶梯奖分（3/5/8/10 → +2/+4/+6/+8）、星级结算（≥90% 三星 +10 分）
- [x] 家长先行流程：登录 → 家长中心 → 创建学生 → 学生工作台
- [x] 登录长期有效：JWT 无过期 + localStorage 持久化，401 自动清理
- [x] 资料库风格 UI 重设计：玻璃卡片、学习地图、底部固定菜单、手机/PC 响应式

### 数据库

- [x] 自研轻量迁移器（golang-migrate MySQL 多语句缺陷替代方案）
- [x] 双方言迁移脚本（`migrations/sqlite/` + `migrations/mysql/`）
- [x] 生产切换 MySQL，空库自动建表 + 种子数据，真实库全链路验证通过
- [x] MySQL 兼容修复：保留字反引号、nullable username、`ON DUPLICATE KEY`、`LastInsertId()`

## 进行中 🚧

- [ ] 217 容器更新为 MySQL 数据源版本（需服务器上 `docker compose pull && up -d`）
